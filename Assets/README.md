# AgenticClean icon

AgenticClean-icon.png is the user-approved second logo concept, generated with the built-in Imagegen tool. Original artwork is retained without destructive edits. scripts/build.sh resizes it into standard macOS icon representations and packages AgenticClean.icns before signing.

Prompt direction: graphite rounded-square macOS tile, turquoise AC-like symbol formed by three substantial cooperating curved segments, clear negative-space gaps, generous empty center, restrained satin dimensional highlights, no text, robot face or tiny network details; transparent outside the tile.
